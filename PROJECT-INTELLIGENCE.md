## What this project is

Mission Control is a **local-first control centre** for a personal ecosystem of applied-AI projects, books, research programmes and commercial work. Its declared purpose is coordination, not replacement: it answers what matters today, where work stopped, which evidence already exists, what can be launched safely, and what should happen next (`README.md`, `pyproject.toml` description "Local-first control centre for an ecosystem of applied-AI projects").
