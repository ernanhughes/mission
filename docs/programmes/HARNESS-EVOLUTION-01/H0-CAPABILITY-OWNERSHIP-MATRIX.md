## Key ownership judgment

“Harness” is a logical control system spanning capability providers. Worker is the candidate execution substrate, not necessarily the owner of context compilation, memory, ECK policy learning, effectiveness, test governance, or human approvals. The best current target is federated composition with explicit contract references and one trace identity lineage.
