# H7 integration inputs (design handoff only)

H7 remains unauthorized. This document records prerequisites for later design; it authorizes no Stephanie implementation or model call.

1. A read contract over verified Mission-to-Worker links: episode/objective, request and operation IDs, strategy/version/digest, policy/configuration, invocations, decisions, resource evidence, evaluation, acceptance, and provenance.
2. Explicit unavailable/truncated indicators and retention horizons; never treat absent history, cost, provider inference, or enforcement as zero/false.
3. A recurring-pattern query defined over protected, comparable records, with minimum sample and held-out cases set before looking at candidate outcomes.
4. Candidate strategy changes isolated from Worker production catalogue; exact candidate source/config identity and bounded baseline/candidate execution manifests.
5. Praxis/independent evaluator ownership, held-out evaluation data, and Mission human decision authority; Stephanie cannot alter evaluators, permission boundaries, acceptance, or promotion.
6. Reproducible budget controls, task-level authorization, project scope, and rollback/retention plan.
7. Inspect capabilities stay descriptive until invocation contract, permissions, Worker adapter, and independent evaluation are verified separately.

H6 provides a read-only starting surface. One scripted fixture does not establish recurring failures or effectiveness.
