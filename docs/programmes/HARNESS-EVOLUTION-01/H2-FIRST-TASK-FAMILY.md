# H2 First Task Family

**Selected:** read-only inspection of one frozen `package.json` artifact, answering exact questions about its declared `name`, `version`, and dependency keys. H3 uses a local synthetic fixture copied into a temporary directory; it never scans a live repository.

Fixture `HE-PKG-001`, path `package.json`, bytes `{ "name":"fixture-worker", "version":"1.2.3", "dependencies":{"alpha":"^1.0.0","beta":"~2.0.0"} }`. The expected tuples are (`package.json`,`name`,`fixture-worker`), (`package.json`,`version`,`1.2.3`), (`package.json`,`dependency`,`alpha`) and (`package.json`,`dependency`,`beta`). The output contract is `{ "schema":"harness.inspection-result.v1", "findings":[{"path":string,"fact":"name"|"version"|"dependency","value":string}] }`.

Exact evaluator: reject malformed JSON/schema, duplicate tuples, unknown paths/facts, and values absent from the frozen source. PASS requires exact tuple-set equality; PARTIAL means a non-empty proper subset with no incorrect or extra tuple; FAIL means any incorrect, duplicate, or unsupported tuple; INCONCLUSIVE means the fixture itself fails digest/schema admission; NOT_EVALUATED means evaluation was explicitly skipped. Model self-report is ignored. Include golden exact, missing-finding, wrong-value, duplicate, extra-finding, and malformed-output cases.

The WorkerService demonstration uses an in-process deterministic test executor registered only by the focused test/demo. It has no network, model, tools, or write capability. Output and manifest/evaluation are retained only under a temporary per-attempt artifact directory with fixed filenames, fixture digest, attempt ID, and content digest. This demonstrates Worker lifecycle/recording, not model reasoning or a live engine comparison. A live model route is deferred: the source defines the DeepSeek Free route, but bounded availability is unverified and current Pi/model executors do not enforce all proposed H3 token/time limits. No production repository scan, write-enabled executor, or production data is part of H3.
