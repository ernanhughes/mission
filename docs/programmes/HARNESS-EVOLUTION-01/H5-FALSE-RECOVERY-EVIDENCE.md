# H5 false-recovery evidence

The deterministic bundle `h5-fixtures/runs/deterministic-20261125-d/` gives every strategy identical fenced text containing the correct answer. Direct and structured return that raw text and fail the pinned raw-JSON evaluator after one call. Corrective makes its permitted second call but still returns the same fenced text and fails. Adaptive applies only `json-fence.v1`, retains the raw invocation, returns the normalized JSON, and passes. The independent verifier reports five total scripted calls and `storage_isolated: true`.

This is a frozen mechanism demonstration, not a claim that adaptive improves model reasoning or generalizes. The valid-structure/wrong-semantics test confirms the harness does not claim to know the correct answer absent an independent evaluator. The earlier Praxis false-recovery finding remains a design constraint: recovery must be grounded in observable faults, and unknown cause stays unknown.
