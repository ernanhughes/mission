# W3-CALIBRATION-REPORT — Synthetic corpus (deterministic; model half gated)

## Purpose

Bounded reference set with expected outcomes, independent of the system being
evaluated (expectations written by hand in `test_work_extract.py` /
`triage` tests, never generated by the extractor).

## Deterministic half (passing, 10 + 12 tests)

- Objective extraction: task-episode → inferred objective; chain/cluster →
  abstain (tested via `extract_episode_deterministic`).
- Authority classification: schema enum enforced; unsupported authority
  rejected (test).
- Accepted vs unaccepted proposals: acceptance requires evidenced
  authorization — deterministic path never promotes (no test_claim becomes
  `accepted_proposal` without a model; recorded as design gap for model half).
- Quoted historical instructions: parser only reads user-role text; assistant
  text never becomes `explicit_user` (unit-covered via role separation).
- Supersession/dedup: idempotence cache (`UNIQUE(input_digest, schema,
  prompt, extractor)`) tested; versioned supersession rows exist in schema.
- Constraint extraction: `kind=constraint|gate` supported in schema;
  deterministic path abstains (no invented constraints).
- Claim classification: CLAIMED signals → claims with claimant/scope/source;
  qualification preserved.
- Evidence binding: W2 links carried as candidates with method/confidence.
- Unknown-source rejection, fabricated-structure rejection, oversize
  rejection, invalid-authority rejection: all tested with adversarial fixtures.
- Abstention: requirements deliberately unextracted deterministically;
  recorded in every envelope (`requirements: 0`).

## Deferred to gated model half

Prompt-injection resistance under live content, deferral/supersession
adjudication, multi-objective disambiguation quality, precision/recall on
real sessions. Sizes: ≤20 invocations, ≤$1. No production-grade statistical
claims will be made from this pilot (per §17: report rates + denominators +
annotation limits, not significance).
