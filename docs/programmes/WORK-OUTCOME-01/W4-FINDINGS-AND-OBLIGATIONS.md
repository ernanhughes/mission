# W4-FINDINGS-AND-OBLIGATIONS — Actionable, deduplicated, non-executing

Findings are synthesized from verdicts, never invented: missing_requirement
(mandatory + no evidence + corroborated gap), defect (contradicted),
verification_gap (reported-but-unverified mandatory, the most common pilot
outcome), unsupported_claim (completion/test/review assertions without
corroboration), authorized deferrals recorded as status=authorized (not
problems). Severity: major for mandatory/blocking, minor for gaps.
Status starts `suspected`; confirmation belongs to re-verification (W7).

Deduplication key is (episode, requirement, kind) — wording-independent,
so 47 repeated claims produce one finding per underlying requirement.
Findings carry evidence refs, impact, next action and closure criteria;
the evaluator never commits, pushes, deploys or executes follow-ups (no
code path exists for it). Full corrective-work integration is W7.

Pilot yield: 2 verification gaps with next actions ("supply verification
evidence"), 1 missing-requirement set. Small, honest, and each closable.
