# W7-USER-GUIDE — Turning findings into verified work

**Application**: Activity → Work Evaluation (operational `:8790`
serves the W6 build until the operator deploys W7; W7 screens below
verified on an isolated full-copy stack — same code, scratch data).

## The loop

1. **Discover**: Outstanding Work → Groups (24 groups, nothing hidden).
   Each group names its recommended action and closure criteria.
2. **Consolidate**: drill into members; one "Generate corrective
   commission" creates a single-episode proposal per affected episode
   (duplicates return the existing proposal — never two).
3. **Prepare**: Proposals tab → inspect → Preview commission (13
   sections) → Copy for wherever the work will run. Scope edits void
   prior approvals (version bump shown).
4. **Authorize**: Submit for review → Approve (type your name +
   confirm click). Reject/Defer with reasons. Nothing self-authorizes.
5. **Execute**: Record manual handoff (route + external reference).
   Mission Control does not run the work; the link traces it.
6. **Verify**: new evidence (test receipts, remote refs, reviews) is
   linked to the requirement/episode; re-evaluate the episode.
7. **Close**: finding closure requires cited evidence + named human;
   reopening keeps the full history.

## Requirement confirmation

Episodes → Requirements: Confirm / Amend (creates v+1, supersedes
old) / Reject / Defer / Insufficient — reviewer name mandatory.
Decisions show on each requirement with provenance. The 20+ episode
backlog stays unconfirmed until reviewed; nothing auto-confirms.

## What stays manual and off

Scheduled evaluation: OFF. Paid inference: $0, unwirable.
Auto-execution / auto-close / auto-confirm: do not exist. Opening any
view performs only GETs.
