# W8D-REVIEW-EVIDENCE-INTEGRATION — Independence is graded, not assumed

Review evidence links carry: work id, objective, applicable
requirements, reviewed revision, reviewer identity AND model family,
scope, findings, reproduction evidence, verdict, outstanding
obligations (`review_ref` on the execution link; detail lives in the
review system).

Grades (never conflated): implementer self-check < same-family
independent agent < cross-family review. A review applies only to the
revision and scope actually reviewed. The W8 pilot's checks are
self-executed + independently re-runnable (commands recorded) — that
is reproducibility, not independent review, and the completion
assessment says so (reported, outcome mixed→partial path).

W6/W7 review obligations carried: cross-family W1–W5 review,
8+4 re-verifications, W6/W7 independent-review residuals (all Low/Info
except F1-Medium-documented).
