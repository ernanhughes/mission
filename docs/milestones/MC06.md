# MC06 — Application adapters

## Adapter framework

- Independent `Adapter` contract with target, availability, capabilities, observations, recommendations and error.
- Per-adapter timeout, exception isolation, persisted `AdapterStatus`.
- Source attribution on every observation: application/project, adapter, external ID, evidence reference, observed time, provenance.
- Dedupe of observations and recommendations across repeated refreshes.
- No adapter writes into the target application.
- Adapter failure cannot take down the dashboard.

## Real adapters

| Adapter | Verified source | Output |
| --- | --- | --- |
| Language | Book chapter files + planning status | Chapter count and status reference |
| Inference | Chapter files + README status claim | Chapter count and dated external claim |
| Math | MATH01 report v1 | 4 claim assessments, tool capability summary, derived obligation review suggestions |
| Next | Local SQLite snapshot | Up to 8 recent opportunities, explicitly a snapshot |
| CoCoder | Configured review JSON artifact | Review summary/findings, high-severity review suggestions |
| Worker | `/health` | Availability/version only |
| Work | None configured | Blocked diagnostics, no fabricated opportunities |
