## Honest limitations

- Work opportunities are not displayed because no verified read-only export was configured.
- Writer/Improve/BookBuilder/Stephanie/Workbench have no adapters.
- Next reads a local SQLite snapshot, not PostgreSQL.
- CoCoder needs a configured review artifact.
- AI provider integration was only validated for offline/failure fallback, not live model quality.
- No Playwright browser automation suite was added; browser smoke was performed with the local browser harness and DOM inspection.
- Retention settings are stored but cleanup is not automated.
- Automatic startup of application profiles is intentionally absent; activation is explicit.

These limitations are surfaced in the UI and not disguised as success.
