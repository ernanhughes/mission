# MC03 — Working dashboard

## Delivered pages

- Today: current focus, latest checkpoint across projects, pending reviews, priority books with reordering, pinned applications, daily briefing, activity, outcomes and stats.
- Projects: search, kind filter, pin/unpin, priority reordering, add project.
- Project workspace: overview, repositories/Git, book link, checkpoints, tasks, decisions, recommendations, adapters, activity.
- Applications: search/filter, real status, launch/stop/restart, repository, URL, logs, full configure/register form.
- Books: three first-class book workspaces with selection, editing, priority order and evidence limits.
- Activity: filters, notes, provenance key and chronological groups.
- Settings: roots, exclusions, scan/cancel, candidates, editor/browser, process limits, adapters, AI, startup profile, retention.

## Real API usage

Every page consumes the FastAPI backend; there is no hardcoded dashboard fixture in production. Loading, empty, error and disabled-capability states are present.

## UX safeguards

- Disabled actions carry reasons and a why-unavailable disclosure.
- Book status is explicitly labelled user-maintained.
- Unavailable adapters display diagnostics, not fabricated content.
- The AI button only appears when AI is configured; the deterministic briefing always works.
