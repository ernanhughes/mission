# MC07 — AI-assisted briefing

## Delivered

- Deterministic briefing from priority books/projects, latest checkpoints, user tasks, pending recommendations and adapter status.
- Provenance on every item: recorded checkpoint, user priority, user task, external claim, derived observation, AI recommendation.
- Optional AI interpretation through an OpenAI-compatible endpoint.
- Requires explicit enablement, consent, base URL and model; API key read from a named environment variable.
- Explicit request (`use_ai: true`); no automatic paid calls.
- Timeout and invalid response fallback to deterministic briefing.
- AI suggestions are appended after deterministic items and cannot replace human decisions.
- No autonomous action.

## Verification

- Grounded briefing test creates a Math checkpoint and task; generated content contains the checkpoint summary and correct provenance.
- Requesting AI without configuration returns deterministic output with `ai_not_configured`.
- Provider failure returns deterministic output with an error; dashboard remains available.
- `test_security.py` verifies API keys are neither stored nor returned.
- A real deterministic briefing was generated through the UI during acceptance.

## Not done

No live paid provider call was made. No model was configured during acceptance. This is intentional and is a documented condition of the test, not a claim that AI quality was verified.
