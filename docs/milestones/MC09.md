# MC09 - Unified application interface

## Scope

Make Next, Work and CoCoder usable inside Mission Control without merging their
codebases or replacing their engines. Movies remains out of scope.

## Honest limitations

- Next has no stable JSON resource API. The live adapter is a read-only database
  compatibility integration, not a supported Next contract.
- Work decisions remain `local_only`; no Work write/synchronisation contract was
  approved.
- Next discovery cannot be launched from Mission Control because no bounded,
  reviewed operation contract exists.
- CoCoder action cancellation and streaming output are not implemented.
- CoCoder retains at most 400 findings per review artifact in its read model.
- Work results/income are not available from the read-only CLI export, so they
  are not inferred.
- Writer, Worker and other applications remain outside this milestone.
