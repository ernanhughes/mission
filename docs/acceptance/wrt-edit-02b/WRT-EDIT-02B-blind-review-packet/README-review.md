# WRT-EDIT-02B blind review packet

This packet contains 50 real passages. It deliberately contains no book names,
diagnostic categories, Writer scores or findings.

Use only:

- `calibration-blind-passages.csv`
- `calibration-review-template.csv`

For each passage in the template, record:

| Field | Scale |
| --- | --- |
| `overall_readability_1_5` | 1 = very hard to read, 5 = very easy to read |
| `density` | `too_dense`, `appropriate`, `too_sparse` |
| `fragmentation` | `too_fragmented`, `appropriate`, `too_continuous` |
| `rhythm` | `too_uniform`, `appropriate`, `too_irregular` |
| `lexical_difficulty` | `low`, `moderate`, `high` |
| `structural_clarity` | `clear`, `mixed`, `unclear` |
| `genuine_issue` | `yes`, `no`, `unsure` |
| `notes` | What the passage is doing, whether the issue is real, and what context matters |

Do not consult the WRT-EDIT-02A sample map or reports until labels are frozen.
Some excerpts are truncated at 1,600 characters, and code/math projection may
have removed identifiers or operators. Record those as contextual limitations,
not prose defects.

This is a text-only packet. Return the completed template unchanged in shape.
