## What was built (Gate B/C)

- `POST /api/writer/evaluations/ingest` — strict validation (schema id, required fields, sha256 shape, qualified providers `artifact|qc` only, list shapes), then idempotent store into existing `integration_records` (`resource_type="writer_evaluation"`, `external_id=evaluation_id`). Replay → `created:false`, nothing written. New ID for same provider+chapter → previous current marked historical (history rows never modified/deleted). Unknown provider / malformed envelope → 422, nothing stored.
- `GET /api/writer/evaluations[?project_id&provider&current_only]`, `GET /api/writer/evaluations/chapter?project_id&chapter_id[&source_hash]`, `GET /api/writer/evaluations/{evaluation_id}`.
- Derived freshness per evaluation: hash equal → CURRENT; different → STALE; no hash resolvable → UNVERIFIED; envelope `unavailable` → UNAVAILABLE; no records → NOT_RUN. Overall follows current rows. Server-side hash resolution via book `manuscript_paths` (exactly-one-candidate rule; ambiguity refuses).
- No migration, no new table, no shared DB, no prose/technical/publication writes, no composite (key-scan tested), no technical-verdict inference (family codes preserved; "VERIFIED" absent).
